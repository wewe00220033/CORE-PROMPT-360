# 🚀 الإطلاق والنشر والتراجع — Release, Deploy & Rollback (`v3.1`)

> مرجع "جميع الحالات" للنشر الآمن: لا تنشر ما لا تملك الرجوع منه، ولا تعتمد على الذاكرة وقت الضغط.
> **البوابة الحتمية:** قبل أي إطلاق إنتاجي مرّر خطة النشر على `python3 scripts/lock360.py deploy-gate --output <خطة_النشر>` (يرصدها فحص `F-DEPLOY-GATE` تلقائياً عند طلبات النشر في `M/L`).

## 1) قبل النشر (Pre-flight)

- **النطاق والأثر (`3.2`):** ما الذي يتغير؟ ما الذي لن يتغير؟ ما الـ Blast Radius؟
- **التحقق والنظافة (`DG-01`):** `verify_repo.py PASS` + `eval PASS` + مراجعة الـ diff بعد آخر تعديل، بلا أسرار أو ملفات مؤقتة.
- **النسخ الاحتياطي (`DG-02`):** نسخة احتياطية / snapshot مؤكدة بالبصمة لقاعدة البيانات والإعدادات قبل أي تغيير لا رجعة فيه.
- **خطة رجوع بزمن محدد (`DG-03`):** خطوات/أمر Rollback مكتوب ومجرّب مع زمن الرجوع المتوقع (`ETA` بالدقائق).
- **المالك ونافذة النشر (`DG-04`):** المالك والمسؤول المناوب (`Owner / on-call`) محددان بالاسم، مع استقرار الاعتماديات وتجنّب أوقات الذروة.

## 2) أثناء النشر (Deploy)

- **نشر تدريجي إن أمكن:** `canary` / `staged rollout` / `feature flag`.
- **راقب المؤشرات (`DG-05`):** لوحة الأخطاء، زمن الاستجابة، الطوابير، معدل النجاح، ولوجات السيرفر الحية.
- **لا تغييرات متوازية:** جمّد أي تغييرات غير مرتبطة أثناء نافذة النشر لحصر سبب أي خلل في متغير واحد.
- **وثّق اللحظة:** رقم الإصدار، الـ commit SHA، التوقيت، المنفّذ، وحالة المؤشرات بعد النشر.

## 3) بوابة القرار (`GO / NO-GO / ROLLBACK` — `DG-07`)

- **GO:** المؤشرات طبيعية، الدليل الفعلي مكتمل، لا أخطاء حرجة جديدة، والقرار موثق صراحةً.
- **NO-GO:** نقص دليل أو اعتماد غير جاهز أو نافذة غير آمنة — أوقف النشر قبل البدء.
- **ROLLBACK:** خطأ حرج، تدهور مؤشر، أو شك عالي — ارجع فوراً بالمسار المعدّ ثم حقّق بهدوء.

## 4) بعد النشر (Post-deploy — `DG-06`)

- **اختبار دخان حي (`Smoke test`):** فحص نقطة صحة الخدمة (`/health`) + عملية قراءة/كتابة حقيقية + المسارات الحرجة بعد النشر.
- **مراقبة قصيرة مكثفة:** أول `15-60` دقيقة حسب خطورة التغيير.
- **تنظيف وتوثيق:** أغلق الأعلام المؤقتة، احذف الملفات المؤقتة، سجّل النتيجة في الـ changelog والذاكرة.
- **التحسين الوقائي:** ما الذي كاد يفشل؟ أضف قفلاً استباقياً أو اختباراً أو استخدم `/patch-360`.

## 5) قائمة الفحص السباعية السريعة (`DG-01..07`)

```text
- [ ] DG-01 Diff / verify PASS (اختبارات وتحقق بعد آخر تعديل)
- [ ] DG-02 Backup / snapshot ready (نسخة احتياطية قبل البدء)
- [ ] DG-03 Rollback + ETA (خطوات رجوع واضحة بزمن محدد)
- [ ] DG-04 Owner / on-call (مالك ومناوب النشر محددان)
- [ ] DG-05 Metrics / logs (مراقبة الأخطاء واللوجات مفتوحة)
- [ ] DG-06 Smoke test (اختبار دخان حي بعد النشر)
- [ ] DG-07 Decision logged (قرار GO / NO-GO / ROLLBACK موثق)
```
