3. فيزياء الطاقة والوقت + العامل البشري (دوافع الطرف الآخر + تطابق السمع والفهم) واللحظة اللي الكل فيها فاكر إن التاني شايل الموضوع.
4. "اختبار الحقيقة": إيه [✅ المؤكد] وإيه [⚠️ المستنتج] وإيه [❓ المجهول]؟ وإيه الشكل اللي بيقول تمام وهو مش تمام؟
5. "الناقد الصريح بعيون جديدة / Steelman": أقوى اعتراض من الطرف التاني وإزاي أرد عليه بصدق وحكمة + نقطة التراجع الآمنة.
6. اسألني أي سؤال يوضح الصورة لو لسه في حاجة غامضة، واختم بورقة واحدة مرتبة فيها الخلاصة وأول خطوة.

## 🔍 4. بوابة فحص ما بعد إنهاء المهمة (`Gear P — Post-Task 4-Gate`)
> مطابقة حرفياً لترس **`P`** في [`../gist/01-CORE-PROMPT-360-v3.md`](../gist/01-CORE-PROMPT-360-v3.md) (تُشغَّل تلقائياً في `L1` على الأعمال غير التافهة فقط — أكثر من ملف أو منطقة حساسة أو خطة):

1. **المتبقي والثغرات (`3.2` / `3.9`):** هل بقيت ثغرة، حالة حدودية، أو ملف مؤقت/ميت متروك؟
2. **أمان التسليم ونافذة الانتقال (`3.7`):** هل الحالة والذاكرة والتزامن ومسار الاستئناف متسقون؟ هل توجد نافذة انتقال ضعيفة غير مقفولة؟
3. **الدليل الفعلي لا النجاح الزائف (`3.8`):** هل تم التحقق العملي الملموس **بعد آخر تعديل فعلي**؟
4. **بوابة الاستيضاح (`3.12` / Q-Contract):** هل يوجد قرار تفضيل أو نقطة معلقة تحتاج سؤال المستخدم ولم تُسجَّل؟

### ☑️ قائمة فحص `Auto-Guard` المرجعية (انسخها واشطب قبل إعلان "تم")

```text
- [ ] Ground Truth: النتيجة مثبتة بدليل فعلي (اختبار / لوج / أثر على القرص / بصمة) لا بشكل ظاهري.
- [ ] Blast Radius: لم نلمس شيئاً خارج النطاق المصرّح به ولم نكسر قائماً.
- [ ] Handover: لا توجد نافذة انتقال / حالة سباق غير مقفولة (Lock / Idempotency / Checklist).
- [ ] Assumptions: لا يوجد [❓ مجهول] جوهري متروك — تحوّل إلى سؤال مسجّل في Q-Contract.
- [ ] Leftovers: صفر ملفات مؤقتة أو عمليات يتيمة أو كود ميت.
- [ ] Rollback: مسار رجوع واضح في أقل من دقيقتين لو ظهر خلل.
- [ ] Next action: أول خطوة آمنة خلال 24 ساعة محددة باسم ومسؤول.
- [ ] Audit: مرّ المخرج على lock360.py audit (الفحص الهيكلي A · كشف الانحراف F · تنبيهات الضجيج M) وصفر 🔴 متبقٍ.
```

## 📋 7. قالب سجل الأسئلة التفاعلي — `Q-Contract` (مطابق لـ `3.12`)
> كل سؤال يُطرح في `3.12` يحمل رقماً ثابتاً `[Q1]`..`[Qn]` لا يتغير أبداً، وفي كل جولة متابعة يُفتح الرد بسجل الأسئلة وبوابة الفهم:

```text
📋 سجل الأسئلة — متبقي [X] من أصل [Y]
- [Q1] ✅ مكتمل — فهمت إن [تلخيص إجابة المستخدم وما حسمته].
- [Q2] ⚠️ جزئي [25% / 50% / 75%] — فهمت إن [الجزء الواضح]، بس لسه ناقص [النقطة الغامضة].
  إعادة شرح: [صياغة مختلفة تماماً بكلمات أبسط + مثال جديد لم يرد سابقاً].
- [Q3] ❌ محتاج توضيح — فهمت [ما وصل]، لكن يحتاج إعادة توضيح لأن [السبب].
  إعادة شرح: [تبسيط مختلف + مثال حي].
- [Q4] ❓ بدون رد — لم يتم الرد بعد.
- [Q5] ⏭ تخطي صريح بطلب المالك — (يُستخدم فقط عند طلب المستخدم تخطي السؤال صراحة).
🚦 بوابة الفهم: [HOLD إذا X > 0 | GO فقط إذا X == 0]
```

*(تحت بوابة `HOLD`: يُسمح في `3.13` فقط بخطوات `NR (لا ندم عليها، يعتمد على: —)` المستقلة تماماً).*
