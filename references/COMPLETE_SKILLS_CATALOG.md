## A) المهارة الأساسية المحمولة (Core)

- **`00-lock360-zero-gaps`** — بروتوكول التقفيل الشامل 360° بالضبة والمفتاح.
  - **الحمولة المثبّتة:** `SKILL.md` + `gist/` (النواة والعدسات والأمثلة) + `references/` (المصفوفات والقوائم والقوالب) + `prompts/` (كتل جاهزة + بوستر الموديلات الضعيفة) + `tests/` (`eval_cases.json` + الفكستشرات) + `scripts/lock360.py` (المحرك الحتمي: `route` · `audit` · `qa-audit` · `deploy-gate` · `audit-skill` · `skeleton` · `catalog` · `eval`).
  - **ما تفعله:** أتراس `P/S/M/L`، بوابة الصدق، MECE، Blast Radius، طبقات الدفاع ونقاط التسليم، Zero-Trust، التحليل الهجومي، FMEA، Kill Switch، `Q-Contract`، الفحص الهيكلي وكشف الانحراف والتناقضات (`SC-1..6`).
  - **استخدمها عندما:** تخطط، تراجع، تتخذ قراراً، أو تنهي مهمة غير تافهة وتريد تقفيل الثغرات.
  - **لا تستخدمها عندما:** المهمة تافهة أو سؤال معلومة مباشر — `L1 Auto-Guard` يكفي ولا داعي لترس كامل.

## B) الحزمة المكمّلة الاختيارية (`skills-pack/` — تُثبَّت بـ `-WithPack` / `--with-pack`)

### B1) 23 مهارة مكمّلة (`skills-pack/skills/`)

**الحوكمة والمعمارية والجودة + البحث (9):**
- **`00-architect-sre`:** تقفيل ثغرات 360° معماري، تفتيش أمني، استقرار/SRE، تحليل جذري للأعطال.
- **`00-architectural-cards-protocol`:** كروت معمارية، خلاصة تنفيذية مزدوجة، نقد SRE، ركائز موحدة.
- **`00-bolla-constitution`:** دستور هندسي/حوكمة، تدرّج T0/T1/T2، قوانين ذهبية، مراجعة مزدوجة.
- **`00-dual-agent-copilot`:** تشغيل ومزامنة وكيلين متوازيين مع قاموس جودة ونقد بالدليل.
- **`00-evidence-inspector`:** فاحص بأدلة دامغة — لا قبول لمهمة أو ادعاء بدون مخرجات اختبار/لوج/لقطة/بصمة.
- **`00-reverse-engineer`:** استكشاف واجهات برمجية وبناء تدفقات طلبات بشكل منضبط وموثّق.
- **`01-micro-tasker`:** Vibe Coding + Micro-Tasking إجباري لتقسيم التنفيذ إلى خطوات صغيرة قابلة للتحقق.
- **`02-planning-system`:** قوالب وأدوات تخطيط احترافي وتتبّع.
- **`everything-search`:** بحث فوري بالملفات/المجلدات عبر Voidtools Everything (`ev`).

**تدفق EGM — تصميم ومراجعة وانحراف (7):**
- **`egm-bootstrap`:** إنشاء/تهيئة README للأدلة الفرعية.
- **`egm-brainstorm`:** تحويل أفكار نصف مكتملة إلى فرضيات/أسئلة منظمة.
- **`egm-draft`:** صياغة تصميم قسماً بقسم من brief أو ملاحظات.
- **`egm-drift-report`:** كشف انحراف الوثائق/الكود وإنتاج تقرير قابل للتنفيذ.
- **`egm-resolve`:** معالجة تقارير المراجعين، إصلاحات مقترحة، بوابات قرار.
- **`egm-review`:** تنسيق بروتوكول Goldfish Review متعدد المراحل.
- **`egm-review-loop`:** حلقة مراجعة تنافسية متعددة الوكلاء ضد معايير الجودة.

**Neon / Lakebase — بدائيات الواجهة الخلفية (7):**
- **`neon`:** نظرة عامة واختيار مكونات Neon/Lakebase — نقطة البداية دائماً.
- **`neon-ai-gateway`:** استدعاء نماذج اللغة والتضمينات عبر بوابة موحدة.
- **`neon-auth`:** إضافة مصادقة مُدارة (تسجيل/دخول/OTP).
- **`neon-functions`:** دوال Node.js بلا خادم (طويلة/HTTP) قرب البيانات.
- **`neon-object-storage`:** تخزين كائنات متوافق مع S3 متفرّع مع قاعدة البيانات.
- **`neon-postgres`:** أفضل ممارسات Lakebase Postgres (اتصال، migrations، branching).
- **`neon-realtime`:** استعلامات SQL حية وتفاعلية للتطبيقات/الوكلاء.

## D) سياسة الاكتمال وسلسلة التوريد (واقعية)

- **"شامل" هنا يعني:** فهرسة واضحة + تغطية الحالات الرئيسية + مسار اختيار + تحقق — **لا** ادعاءً بأنه لا يمكن إضافة مهارة جديدة أبداً.
- **قبل تثبيت أي مهارة (خاصة من `skills-pack/` أو مصدر خارجي):**
  1. شغّل `python3 scripts/lock360.py audit-skill <المسار>` — `FAIL` يمنع التثبيت، `WARN` يُدوَّن في بطاقة التسجيل.
  2. أكمل النقاط البشرية في [`SKILL_AUDIT_CHECKLIST.md`](./SKILL_AUDIT_CHECKLIST.md) (الصلاحيات، الشبكة، قراءة السكربتات بعينك).
  3. ثبّت نسخة/commit محدداً وطابق `MANIFEST.sha256`.
- **الحد الأدنى لكل مهارة مُدرجة هنا:** `SA-FRONTMATTER` و`SA-TROJAN-BIDI` و`SA-EXEC-PIPE` و`SA-SECRET` و`SA-INJECTION` خضراء — `verify_repo.py` يفرض ذلك على `skills-pack/skills` في كل تشغيل.
- **عند ظهور فجوة متكررة:** أضف مهارة/مرجعاً عبر `/patch-360` أو PR مرفقاً ببطاقة التدقيق ونتيجة `verify_repo.py` خضراء، وحدّث هذا الكتالوج في نفس الطلب.
- **حدود الصدق:** هذا الكتالوج يصف ما تدّعيه كل مهارة في `SKILL.md` الخاص بها؛ الفحص الآلي يتحقق من الهيكل والسلامة، ولا يضمن أن المهارة تؤدي وظيفتها جيداً — ذلك يُثبته eval مع/بدون المهارة (النقطة 11 في قائمة التدقيق).
