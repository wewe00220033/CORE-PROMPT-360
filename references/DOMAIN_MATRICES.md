## 1️⃣ نظام هندسة البرمجيات، الباك إند، الـ APIs، والتزامن (`Backend & Concurrency`)
- **الحدود والمدخلات (`Perimeter`):** `Null` / فراغ / `NaN` / نصوص دولية وعربية وإيموجي / أحجام تتعدى حد المنصة أو الـ API أو سقف ملف القواعد / حقن المسارات (`Path Traversal`) والأوامر والـ SQL.
- **التزامن وغفوة الحارس (`Concurrency & Locks`):**
  - منع تشغيل عمليتين متزامنتين على نفس المورد أو الجلسة (`PID Lock` / `file_lock` / فحص أخطاء تعارض الجلسات).
  - كتابة آمنة بالاستبدال الذري (`Write tmp + fsync + os.replace`) مع إعادة محاولة محدودة ضد أقفال مضادات الفيروسات أو الفهرسة.
  - منع التكرار عند إعادة المحاولة (`Idempotency Keys` + قيود تفرد في قواعد البيانات الموضعية/المشتركة).
- **الشبكة والاعتماديات (`Resilience`):** مهلات منفصلة (`connect` / `read` / `total`)، إعادة محاولة بـ `Exponential Backoff + Random Jitter` لتفادي العاصفة المتزامنة (`Thundering Herd`)، احترام ترويسة التهدئة وحدود المعدل (`Retry-After`)، وتفعيل `Circuit Breaker` + `Fallback` عند سقوط المزود الخارجي.
- **قيود نظام التشغيل (`OS Quirks`):**
  - في ويندوز: اقتباس المسارات ذات المسافات، الانتباه لعدم حساسية NTFS لحالة الأحرف، أقفال الملفات المفتوحة، وتجنب كسر UTF-8 بالـ BOM غير المقصود.
  - إدارة الموارد: إغلاق المقابض بـ `with`/`try-finally`، عدم حظر الـ event loop/async بعمليات I/O متزامنة ثقيلة على ملفات ضخمة، وتدوير اللوجات وحدود الذاكرة.

## 2️⃣ نظام الأمان ومكافحة الخداع (`Security, Red-Team & Zero-Trust`)
- **حراسة الأسرار (`Zero-Secret Leak`):** فحص آلي قبل الحفظ أو النشر لمنع تسرب مفاتيح الـ API، التوكنات، كلمات المرور، بيانات الدفع، أو الـ PII في السورس والوثائق واللوجات (إلزام `[REDACTED]`).
- **اختبار قناع رامز (`Deceptive Success & Silent Failures`):**
  - رفض الاعتماد على ظاهر `HTTP 200 OK` أو `exit code 0` دون فحص الجسم والـ Trailers لاحتمال خطأ منطقي أو صفحة تحقق/حظر أو حدود كوتا.
  - التحقق من **الناتج المادي النهائي** عند المستقبِل (بصمة `SHA-256`، صف محدث، سطر لوج حي) لا مجرد غياب الـ Exception.
- **عزل المدخلات غير الموثوقة (`Prompt Injection & Least Privilege`):** تغليف البيانات الخارجية بوسوم عزل صريحة وفصل قراءة البيانات عن صلاحيات التنفيذ والأدوات.
- **سلسلة التوريد (`Supply Chain`):** رفض الإضافات الثنائية المغلقة مجهولة المصدر، فحص النطاقات المتشابهة (`Typosquatting`)، وتثبيت نسخ الحزم الحساسة مع بيئات معزولة.

## 3️⃣ نظام الاختبار، الجودة، ومنع التراجع (`QA, Testing & Anti-Regression`)
- **ثلاثي الإثبات (`Test-Before-Talk`):**
  1. فحص التركيب والساكن (`py_compile`, `node --check`, صحة JSON/YAML, فحص تسرب الأسرار).
  2. اختبار المسار السليم + **المسارات السلبية** (مدخل فاسد، فصل الشبكة، تصادم الملف الموجود مسبقاً، حالات الحدود).
  3. **القانون الذهبي:** إعادة التشغيل والتحقق **بعد آخر تعديل فعلي** — أي تعديل لو سطر واحد يبطل صلاحية الاختبار السابق.
- **صرامة المحاكاة (`Strict Mocks`):** الموك المتساهل يزيف الثقة؛ يجب أن يرفض العقود الناقصة والمدخلات الشاذة، ولا يُنسب نجاح الموك لبيئة الإنتاج الحية أبداً.
- **نظافة ما بعد التنفيذ (`Blast Radius & Cleanup`):** إزالة الملفات المؤقتة وبقايا التجارب، وعدم ترك عمليات يتيمة شغالة في الخلفية.

## 4️⃣ نظام الذكاء الاصطناعي، الأتمتة، والوكلاء (`AI, Scrapers & Swarms`)
- **الاقتصاد وحماية الحصص:** بوابة فرز حتمية بـ `0 Tokens` قبل استدعاء النموذج الذكي، مع احترام حدود المعدل والتكلفة.
- **منع الانحراف والحلقات:** حدود عمق وتكرار + فحص تشابه + مخرجات مقيدة بـ `JSON Schema` مع خطة تراجع حتمية عند تعثر الموديل.
- **مناعة الجلسات والحصص:** عدم مشاركة ملفات الجلسة والتوكن بين عمليتين متزامنتين، احترام فترات التهدئة، ومزامنة الفجوات بعد الإقلاع (`Catch-up Sync`) دون تكرار أو فقد.
- **الذاكرة الباردة وتسليم الوكلاء (`Cold-Start Handoff`):** وجود نقطة استئناف مكتوبة بحيث يكمل الوكيل الجديد من آخر حالة مؤكدة بدون هلوسة أو إعادة استكشاف.
