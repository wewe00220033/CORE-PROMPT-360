# 🪫 مسرّع الموديلات الخفيفة — Weak-Model Booster (`v3.0`)

> **المبدأ (من الأدلة في `SOURCES_AND_INSPIRATIONS.md`):** الموديل الصغير لا يستطيع تقييم نفسه بمجرد طلب التزام عامة، لكن التحقق من **الهيكل المنظّم** عبر المحرك الحتمي أو تمريرة تدقيق منفصلة عملية دقيقة ومضمونة.

---

## ⚙️ خطوات التشغيل الأربع (بحد أقصى 3 إصلاحات)

1. **وجّه وحدّد ملف القارئ أولاً:** شغّل `python3 scripts/lock360.py route --text "<الطلب>"` لتحديد الترس (`P/S/M/L`) واللهجة وملف القارئ (`👤 القارئ`). لا تترك الترس `L` في تمريرة واحدة لموديل صغير — قسّمه لتمريرتين (`M` أولاً ثم استكمال `3.8` و`3.10` و`3.13-L`).
2. **الحلّال (`Pass-1`):** أعطِ النموذج [`CORE-MINI v3.0`](../gist/01-CORE-PROMPT-360-v3.md#L139) + ناتج `python3 scripts/lock360.py skeleton --gear <X>` + طلب المستخدم:
   - ممنوع حذف أي عنوان `3.x` أو استبدال الأسماء القياسية بمسميات قديمة.
   - لو غابت معلومة: يكتب `❓ [مجهول]` ويحولها لسؤال `[Qn]` في `3.12`.
   - لو القارئ غير مبرمج: سطر `بالبلدي:` إلزامي تحت كل `⭐` (`3.2`) و`🟥` (`3.3`).
3. **المُحقِّق المستقل (`Pass-2`):**
   - مع توفر Python: شغّل `python3 scripts/lock360.py audit --output <الرد> --gear <X> --request <الطلب>` (+ `qa-audit` في جولات المتابعة و`deploy-gate` عند النشر).
   - بدون Python (تمريرة `Factored` اليدوية): افتح جلسة منفصلة أو أسئلة تحقق مستقلة بدون الثقة بالمسودة:
     - هل ذُكر `👤 القارئ` و`الترس` في `3.1` بدون نسبة `%`؟
     - هل كل مرحلة وسطى في `M <= 4` أسطر، وإجمالي `S <= 350` كلمة؟
     - هل توجد أية تناقضات (`SC-1..6`: باب اتجاه واحد vs ترس `S/M`، سؤال مفتوح مع `لا شيء` في `3.14`، `GO` مع `HOLD`، `🟥` متعارض مع `⬜`)؟
     - هل خلا قسم `3.15` الناقد من عبارة `"كما ذكرت"` والمجاملة؟ وهل التزمت `3.16` بعدد البنود بدون حقائق جديدة؟
4. **الإصلاح المحدود (`Repair`):** أصلح فقط البنود المرصودة (واحداً في كل مرة بحد أقصى `3` محاولات، ثم اعرض الباقي للمستخدم أو انتقل لنموذج أقوى).

## 📋 قائمة `CORE-MINI` المختصرة للنسخ في الموديلات الصغيرة

```text
املأ المراحل التالية بالحرف بالضبط دون حذف أي مرحلة ودون جداول (| col |):
3.1 الخلاصة التنفيذية السريعة: الترس + 👤 القارئ + الحكم + أكبر خطر + أول خطوة (ممنوع % هنا).
3.2 شجرة التفكيك ونطاق الأثر: MECE + ⭐ + سطر بالبلدي: + الموجود الممنوع ينكسر.
3.3 سلّم الالتزامات: ثابت لا يُكسر 🟥 (+ بالبلدي) / مطلوب + بديل 🟧 / تحسين 🟩 / اختيار حر ⬜ / نمط مرفوض 🟨 / خط أحمر + قاطع 🚫.
3.4 فيزياء الواقع والميكانيكا · 3.5 العامل البشري · 3.6 نوع الباب والآثار × 3.
3.7 طبقات الدفاع ونقاط التسليم: وقاية خارجية + عزل داخلي + شروط كامنة + أضعف نافذة انتقال وقفلها.
3.8 كشف النجاح الزائف والدليل الفعلي · 3.9 التحليل الهجومي وكشف الثغرات (مربوط بالطلب).
3.10 سجل المخاطر FMEA (كروت 🔻 رأسية: القفل + خطة التعويض البديلة + Tripwire + AP).
3.11 التراجع والتوقف والموت المسبق (Tripwires + زر الطوارئ + مسار الرجوع + فشل بعد 6 شهور).
3.12 اسألني ولا تخمّن ([Q1].. مرقّمة + ليه مهم) · ثم في المتابعة 📋 سجل الأسئلة + 🚦 بوابة الفهم HOLD/GO.
3.13 خطة التنفيذ (NR المستقلة فقط تحت HOLD + خطوة 24 ساعة في S + DoD في L).
3.14 لوحة الحسم والثقة (✅/⚠️/❓ متسقة مع 3.12 + الثقة % مرة واحدة + شرط انقلاب الحكم).
3.15 الناقد الصريح بعيون جديدة (نقدان ملموسان على الأقل، بلا "كما ذكرت" ولا مديح).
3.16 الخلاصة المنظمة (6 بنود في M/L أو 3 في S بدون أي حقائق أو % جديدة).
```
