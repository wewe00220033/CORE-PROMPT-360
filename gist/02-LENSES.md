## 💻 عدسة 1: البرمجة وهندسة النظم (`Software & Systems`)
> الصق هذا البلوك في `[5]` عند تصميم أو مراجعة أي كود أو أداة أو أتمتة:

```markdown
### 🔭 عدسة إضافية: برمجة وهندسة نظم (Backend · Security · QA · AI/Agents)
- **الأركان ونطاق الأثر (`3.2` / `3.3` Blast Radius):** راجع أثر التعديل على كل عقود الـ APIs/Hooks/Schemas القائمة، وفكّر في حدود المنصة والـ API والأحرف الدولية/الإيموجي. ممنوع كسر القائم أو تسريب الأسرار/PII (`sk-` / `Tokens` / `Bearer`). **ولا تخترع أنماطاً أو ملفات موازية لشيء شغال بالفعل** (ابنِ على القائم أو عدّله صراحةً بدل تكرار نسخة ثانية تتعارض معه لاحقاً)، ولا تلمس ملفات خارج النطاق المصرّح به.
- **التزامن والميكانيكا وقيود نظام التشغيل (`3.4` / `3.7`):**
  - أقفال حقيقية للتزامن (`flock / file_lock`) + استبدال ذري (`Write tmp + fsync + os.replace`) + مفاتيح `Idempotency` لمنع التكرار عند إعادة المحاولة.
  - مهلات منفصلة (`connect/read/total`) + `Backoff + Jitter` + احترام حدود المعدل (`Retry-After`) + `Circuit Breaker` + فحص قيود النظام (مسارات ذات مسافات، ترميز UTF-8 بدون BOM، أقفال الملفات المفتوحة).
  - **قتل شجرة العمليات عند المهلة (`Timeout ⬅ Tree Kill`):** أي عملية فرعية تتجاوز مهلتها تُقتل مع كل أبنائها (لا عمليات يتيمة) + فحص التسرب (`Memory / Temp Files / Handles`) بعد كل تشغيل طويل.
- **الأمان وقناع رامز (`3.8`):**
  - لا تصدّق `HTTP 200 OK` أو `exit 0` لو فيها خطأ منطقي خفي؛ تحقّق من **الأثر المادي والناتج الفعلي** (`SHA-256`، سطر لوج حي، صف قاعدة بيانات).
  - عزل المدخلات غير الموثوقة (`<UNTRUSTED>`) + تثبيت نسخ الحزم الحساسة ورفض الإضافات المغلقة المجهولة.
- **الاختبار والنظافة (`QA Test-Before-Talk`):**
  - مسار سليم + **مسارات سلبية** + اختبارات صارمة (`Strict Mocks` تفشل على مدخل شاذ ولا تُنسب نجاحاتها للإنتاج) + إعادة التحقق **بعد آخر تعديل فعلي** + حذف أي ملفات مؤقتة أو عمليات يتيمة.
- **الذكاء الاصطناعي والوكلاء (`AI & Automation`):**
  - بوابة فرز حتمية بـ `0 Tokens` قبل استدعاء الموديل + سقف خطوات/تشابه لمنع الحلقات + `JSON Schema` مع `Fallback` + ملفات استئناف بارد (`RESUME/STATE`) + حراسة انتهاء الجلسات/التوكن أثناء التشغيل.
- **أسئلة التصيّد التقنية الـ 4 الإضافية (`3.9`):** قيود المسارات/الترميز في نظام التشغيل؟ انتهاء التوكن في منتصف الجلسة (`Mid-Session Expiry`)؟ كذب المحاكاة (`Mock Lying`)؟ تضارب عمليتين على نفس الجلسة/الملف؟
- **نقطة الرجوع (`3.11`):** نسخة احتياطية/فرع واضح + خطوات Rollback في أقل من دقيقتين.
- **قاعدة الإصلاحات الثلاثة (`Systematic Debugging`):** جذر السبب قبل أي إصلاح، فرضية واحدة وأصغر تغيير في كل مرة، ولو فشلت **3 إصلاحات متتالية** = المشكلة معمارية لا موضعية ⬅ توقف وأعد فحص النمط نفسه (حالة مشتركة، اقتران خفي) بدل محاولة رابعة.
```

```markdown
### 🔭 عدسة إضافية: تفاوض وإقناع وبشر
- **أفضل بديل لو فشل الاتفاق (`BATNA`) في 3.11:** لك أنت، وللطرف الآخر — التفاوض بيعتمد على مين عنده بديل أقوى.
- **فهم الطرف الآخر بأقصى إنصاف (`Steelman 3.5`):** إيه الخوف الحقيقي أو الكرامة أو المصلحة اللي بتحرّك الطرف التاني ورا كلامه؟ **وفرّق بين سماعه للكلام وفهمه لنفس المعنى** (أعد صياغة النقطة الحساسة بهدوء للتأكد).
- **الجسور لا حرق المراكب (3.7):** صمّم مخرج "حفظ ماء الوجه" للطرف الآخر عشان يوافق بدون ما يحس إنه اتكسر.
- **نقاط الحمراء والأسئلة الذكية:** حدد ما لا تقبل التنازل عنه + صُغ 3 أسئلة مفتوحة تكشف نيته وميزانيته الحقيقية بدون صدام.
```
